Zaman aşımı ve AbortController

İzlek: http-api · Seviye: orta · Bulunduğu sistemler: claudecode, ecym, obsidian, ollamas

Nedir

fetch'in varsayılan zaman aşımı YOKTUR; yanıt vermeyen bir sunucu isteği süresiz asar. AbortController ile bir zamanlayıcı kurulup signal geçilmelidir; curl tarafında karşılığı --max-time'dır.

Bizde neden böyle yazılmış

Gece koşan sağlık turu, yanıt vermeyen bir servis yüzünden sabaha kadar açık kalabilir ve bir sonraki turu bloke eder. Her dış çağrıda zaman aşımı bu yüzden zorunlu kabul edilir — otomasyonun canlı kalması buna bağlı.

Alıştırma

Zaman aşımı olmadan kapalı bir porta istek at ve süreyi ölç. Sistem varsayılanı kaç saniye?

Uygulanabilir tarif

learnkb apply http-timeout bu programı çalıştırır ve çıktısını beklenenle karşılaştırır (dil: node · sınıf: safe).

(async () => {
  const ac = new AbortController();
  const t = setTimeout(() => ac.abort(), 50);
  const bekle = new Promise((_, rej) => ac.signal.addEventListener('abort', () => rej(new Error('AbortError'))));
  try { await bekle; } catch (e) { console.log('iptal:' + e.message); } finally { clearTimeout(t); }
})();

Beklenen çıktı: iptal:AbortError
