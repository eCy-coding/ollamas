Başlıklar ve setHeader

İzlek: http-api · Seviye: orta · Bulunduğu sistemler: ollamas

Nedir

Başlıklar gövdeden ÖNCE yazılmalıdır; gövde akmaya başladıktan sonra setHeader çağırmak hata verir. Akış (stream) yanıtlarında bu sıra kritik hâle gelir.

Bizde neden böyle yazılmış

SSE uçlarında Content-Type: text/event-stream, Cache-Control: no-cache ve Connection: keep-alive üçlüsü ilk yazılan şeydir. Sıra bozulursa istemci akışı normal bir yanıt sanar ve ilk parçadan sonra bağlantıyı kapatır.

Alıştırma

SSE ucunda başlıkları gövdeden sonra yazmayı dene. Hangi hata gelir?

Uygulanabilir tarif

learnkb apply http-headers bu programı çalıştırır ve çıktısını beklenenle karşılaştırır (dil: node · sınıf: safe).

const yazilan = [];
const setHeader = (k, v) => { if (yazilan.length) throw new Error('ERR_HTTP_HEADERS_SENT'); return k + '=' + v; };
const h = setHeader('Content-Type', 'text/event-stream');
yazilan.push('data: ilk\n\n');
let hata = '';
try { setHeader('X-Late', '1'); } catch (e) { hata = e.message; }
console.log(h + ' | ' + hata);

Beklenen çıktı: Content-Type=text/event-stream | ERR_HTTP_HEADERS_SENT
