Authorization: Bearer — anahtar nerede durur

İzlek: http-api · Seviye: ileri · Bulunduğu sistemler: ollamas

Nedir

Bearer belirteci başlıkta taşınır — URL'de ASLA, çünkü URL'ler günlüklere, tarayıcı geçmişine ve Referer başlığına sızar. Belirteç dosyada duruyorsa o dosya sürüm kontrolünün dışında olmalıdır.

Bizde neden böyle yazılmış

Obsidian Local REST anahtarı .obsidian/plugins/.../data.json içindedir ve vault .gitignore'unun İLK satırlarındandır — .gitignore bilerek git add'den ÖNCE yazılmıştır, böylece anahtar ilk commit'e hiç girmedi.

Alıştırma

git log -S 'apiKey' çalıştır. Anahtar geçmişte hiç görünmüş mü?

Bu depodaki gerçek kullanım

DosyaSatırKod
ollamas:server/github-app.ts10Authorization: 'Bearer ${auth}',
ollamas:server/providers.ts1376"Authorization": 'Bearer ${apiKey}'
ollamas:server/obsidian-rest.ts228headers: { authorization: 'Bearer ${creds.apiKey}' },

Uygulanabilir tarif

learnkb apply http-auth bu programı çalıştırır ve çıktısını beklenenle karşılaştırır (dil: node · sınıf: safe).

const url = 'https://127.0.0.1:27124/search?token=SECRET';
const guvenli = { url: 'https://127.0.0.1:27124/search', headers: { Authorization: 'Bearer SECRET' } };
console.log('url-sizdirir:' + url.includes('SECRET') + ' baslik-sizdirmaz:' + !guvenli.url.includes('SECRET'));

Beklenen çıktı: url-sizdirir:true baslik-sizdirmaz:true
