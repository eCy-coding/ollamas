LIMIT / OFFSET — sınırsız sorgu yoktur

İzlek: data · Seviye: temel · Bulunduğu sistemler: obsidian, ollamas

Nedir

LIMIT n sonuç sayısını keser. Sıralamasız bir LIMIT belirsizdir: hangi n satırın geleceği garanti değildir. OFFSET ile sayfalama büyük tablolarda pahalıdır (atlanan satırlar yine taranır).

Bizde neden böyle yazılmış

recall k parametresi bir LIMIT'tir ve tavanı vardır. Sınırsız bir arama, 26 kB'lık bir yanıtın 260 kB'a çıkması demek olurdu — token bütçesinin ilk savunma hattı bu tek kelimedir.

Alıştırma

ORDER BY olmadan LIMIT 3 çalıştır, sonra indeks ekle ve tekrarla. Dönen satırlar aynı mı?

Uygulanabilir tarif

learnkb apply sql-limit bu programı çalıştırır ve çıktısını beklenenle karşılaştırır (dil: python · sınıf: safe).

import sqlite3
c = sqlite3.connect(':memory:')
c.execute('CREATE TABLE n (id INTEGER, skor INTEGER)')
c.executemany('INSERT INTO n VALUES (?,?)', [(1,5),(2,9),(3,7)])
r = [x[0] for x in c.execute('SELECT id FROM n ORDER BY skor DESC LIMIT 2')]
print('ilk2:%s' % r)

Beklenen çıktı: ilk2:[2, 3]
