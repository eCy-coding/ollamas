async / await — sırayla okunan eşzamansız kod

İzlek: js-ts · Seviye: orta · Bulunduğu sistemler: ollamas

Nedir

async fonksiyon her zaman bir Promise döndürür; await o sözün çözülmesini bekler. Kod yukarıdan aşağı okunur ama bekleme sırasında çalışma zamanı başka işe geçebilir.

Bizde neden böyle yazılmış

Ağ ve süreç çağrıları (brain :3000, alt-model) böyle yazılır. await unutulduğunda fonksiyon Promise { <pending> } döner ve 'sonuç boş geldi' diye yanlış teşhis edilir — bu depoda birden çok kez yaşandı.

Alıştırma

await olmadan bir async fonksiyonun dönüşünü console.log ile yaz. Çıktı neden veri değil?

Uygulanabilir tarif

learnkb apply js-async-await bu programı çalıştırır ve çıktısını beklenenle karşılaştırır (dil: node · sınıf: safe).

const gecikmeli = async (v) => v;
(async () => {
  const bekleyen = gecikmeli('deger');
  const cozulen = await gecikmeli('deger');
  console.log('await-yok:' + (bekleyen instanceof Promise) + ' await-var:' + cozulen);
})();

Beklenen çıktı: await-yok:true await-var:deger
