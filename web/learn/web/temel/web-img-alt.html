img alt — boş alt ile eksik alt farkı

İzlek: web · Seviye: temel · Bulunduğu sistemler: ollamas

Nedir

alt="" (boş) ekran okuyucuya 'bu görsel dekoratif, atla' der. alt niteliğinin HİÇ olmaması ise okuyucunun dosya adını okumasına yol açar. İkisi aynı şey değildir.

Bizde neden böyle yazılmış

Site logosu dekoratiftir ve boş alt taşır; yanındaki metin zaten adı söyler. Nitelik silinseydi ekran okuyucu 'pwa-icon.svg' diye okurdu — gürültü.

Alıştırma

Logodan alt niteliğini kaldır ve VoiceOver ile dinle. Ne okunuyor?

Bu depodaki gerçek kullanım

ollamas:web/embed-demo.html13<a class="brand" href="/web/"><img src="/pwa-icon.svg" alt="" width="28" height="28" /><span>ollamas</span></a>

Uygulanabilir tarif

learnkb apply web-img-alt bu programı çalıştırır ve çıktısını beklenenle karşılaştırır (dil: node · sınıf: safe).

const html = '<img src="/pwa-icon.svg" alt="" width="28">';
const m = html.match(/alt="([^"]*)"/);
console.log('alt-var:' + Boolean(m) + ' dekoratif:' + (m && m[1] === ''));

Beklenen çıktı: alt-var:true dekoratif:true
