Flexbox ve Grid — düzenin iki aracı

İzlek: web · Seviye: orta · Bulunduğu sistemler: obsidian, ollamas

Nedir

Flexbox tek eksende dizer (satır ya da sütun), Grid iki eksende yerleştirir. Kart ızgarası için grid-template-columns: repeat(auto-fill, minmax(240px, 1fr)) deseni, medya sorgusu YAZMADAN responsive olur.

Bizde neden böyle yazılmış

Açılış kart-ızgarası tam olarak bu desendir; kırılma noktası sayısı sıfırdır. Sabit sütun sayısı verilseydi her ekran genişliği için ayrı bir @media bloğu gerekirdi ve site 3 yerine 8 kuralla bakılır olurdu.

Alıştırma

minmax(240px, 1fr) yerine sabit 1fr 1fr 1fr yaz. 400 piksel genişlikte ne olur?

Bu depodaki gerçek kullanım

DosyaSatırKod
obsidian:help/_web/assets/style.css44.topbar .spacer{flex:1}
obsidian:help/_web/src/style.css44.topbar .spacer{flex:1}
obsidian:_bin/claude-code-dashboard.html42@media(max-width:720px){.cols{grid-template-columns:1fr}}

Uygulanabilir tarif

learnkb apply css-flex-grid bu programı çalıştırır ve çıktısını beklenenle karşılaştırır (dil: node · sınıf: safe).

const rule = 'grid-template-columns: repeat(auto-fill, minmax(240px, 1fr))';
const w = 1000, min = 240;
console.log('sutun:' + Math.max(1, Math.floor(w / min)) + ' kural-medyasiz:' + !rule.includes('@media'));

Beklenen çıktı: sutun:4 kural-medyasiz:true
