localStorage — kalıcı küçük durum

İzlek: web · Seviye: orta · Bulunduğu sistemler: obsidian, ollamas

Nedir

localStorage yalnız METİN saklar; nesne koyacaksan JSON.stringify gerekir. Alan doluysa ya da tarayıcı özel moddaysa setItem İSTİSNA atar — bu yüzden çağrı try içine alınmalıdır.

Bizde neden böyle yazılmış

Tema tercihi burada tutulur. file:// altında bazı tarayıcılar depolamayı kısıtlar; sarmalayıcı try olmadan sitenin TÜM betiği ilk satırda çökerdi ve arama da tema da çalışmazdı.

Alıştırma

Uygulanabilir tarif

learnkb apply web-localstorage bu programı çalıştırır ve çıktısını beklenenle karşılaştırır (dil: node · sınıf: safe).

const store = { veri: {}, setItem(k, v) { if (k === 'kilitli') throw new Error('QuotaExceeded'); this.veri[k] = String(v); } };
let saglam = true;
try { store.setItem('kilitli', 'dark'); } catch { saglam = true; }
store.setItem('tema', 'dark');
console.log('tema:' + store.veri.tema + ' sayfa-ayakta:' + saglam);

Beklenen çıktı: tema:dark sayfa-ayakta:true
