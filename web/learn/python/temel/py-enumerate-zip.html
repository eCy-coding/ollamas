enumerate ve zip

İzlek: python · Seviye: temel · Bulunduğu sistemler: claudecode, ecym, obsidian

Nedir

enumerate indeks ile elemanı birlikte verir; elle sayaç tutmayı gereksiz kılar. zip iki diziyi eşler ve KISA olanda durur — uzunluklar farklıysa sessizce veri kaybedebilirsin.

Bizde neden böyle yazılmış

Satır numarası üretirken (for i, line in enumerate(lines, 1)) kanıt satırı dosya:satır biçiminde yazılabilsin diye kullanılır. Bu tier'ın tüm örnekleri o satır numarasına dayanır.

Alıştırma

3 ve 5 elemanlı iki listeyi ziple. Kaç çift çıkar, kaç eleman düşer?

Uygulanabilir tarif

learnkb apply py-enumerate-zip bu programı çalıştırır ve çıktısını beklenenle karşılaştırır (dil: python · sınıf: safe).

lines = ['import os', 'def f():', '    return 1']
hits = [(i, l.strip()) for i, l in enumerate(lines, 1) if 'def' in l]
print('satir:%d icerik:%s duseng:%d' % (hits[0][0], hits[0][1], len(list(zip([1,2,3], [1,2])))))

Beklenen çıktı: satir:2 icerik:def f(): duseng:2
