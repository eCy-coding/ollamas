eCym Pipeline

An 18-step, evidence-based AI pipeline with no blind spots: `` search → think → analyze → plan → todo → sandbox_test → think → analyze → test → true_or_false → chaos_test → security_scan → coverage_check → code → test → merge → commit → push ` It is **not a prompt an LLM answers**. It is a DAG (pipeline/workflow.json`) executed by an orchestrator that measures every step, evaluates hard SLOs, injects faults, scans for vulnerabilities, and refuses to call itself complete when any capability went unexercised.
