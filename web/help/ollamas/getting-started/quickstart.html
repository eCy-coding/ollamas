Hızlı Başlangıç

ollamas'ı sıfırdan çalışır hale getiren adımlar (README 'Hızlı başlangıç' bölümünden).

1. Ön-koşulları hazırla

Idempotent hazırlık: Node kontrolü, npm ci, .env kopyası, ollama daemon doğrulaması, varsayılan model çekme, derin audit. Yerel kullanım için API key gerekmez.

npm run ready

2. Sunucuyu başlat

Geliştirme sunucusu http://localhost:3000 üzerinde ayağa kalkar (veya make up).

npm run dev

3. Sağlığı doğrula

node/ollama/bridge/app derin sağlık denetimi; gateway/ollama/bridge/ready paralel problanır.

npm run doctor
