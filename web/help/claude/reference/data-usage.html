data usage

Anthropic'in Claude için veri kullanım politikaları. - Bireysel kullanıcılar (Free, Pro, Max): Verinizin gelecekteki Claude modellerini iyileştirmek için kullanılmasına izin verme seçeneği sizindir. Bu ayar açıkken (bu hesaplardan Claude Code kullanımı dahil) Anthropic yeni modelleri bu veriyle eğitebilir. - Ticari kullanıcılar (Team, Enterprise, API, 3. taraf platformlar, Claude Gov): Anthropic, ticari şartlar altında Claude Code'a gönderilen kod veya promptlarla üretken model eğitmez; müşteri veri sağlamayı seçmedikçe (örneğin Development Partner Program). Development Partner Program: Bir kuruluş yöneticisi kuruluşu için açıkça opt-in yapabilir.
